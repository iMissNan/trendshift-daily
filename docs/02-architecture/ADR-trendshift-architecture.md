## 2. 核心模块与职责契约

### 2.1 模块 1：采集器 (`src/trendshift_daily/collect.py`)
- **职责**：拉起无头 Chromium 抓取 Trendshift 5 个固定路由页面，滚动 6 轮加载完全。
- **契约**：
  - 严守**保序去重**，绝不私自过滤或删除源数据任何项目。
  - 单榜有效仓库数下限检查（阈值 ≥20），低于下限立即阻断并上报。

### 2.2 模块 2：元数据与 README 抓取器 (`src/trendshift_daily/enrich.py`)
- **职责**：通过 GitHub 官方接口拉取客观事实与 README 全文。
- **契约**：
  - 一票否决硬触发：`archived: true` 或 `(now - pushed_at) > 730天`，直接生成否决标记。
  - README 实行滑动窗口截断（首部 6000 字符 + 尾部 2000 字符），防止爆上下文。

### 2.3 模块 3：研判与规则引擎 (`src/trendshift_daily/analyzer.py`)
- **职责**：调用 10Router 网关，输出四键结构化分析（是什么、对我们有什么用、局限性、依据来源）。
- **契约**：
  - 强校验 JSON Schema；解析失败具备 1 次重试容错；仍失败标 `analysis_failed`，严禁脑补。
  - 依据来源（`evidence`）必须明确指向字段或 README 标题段落。

### 2.4 模块 4：卡片渲染与推送器 (`src/trendshift_daily/render_push.py`)
- **职责**：飞书交互卡片组装、折叠面板构建、拆页控制、网络投递与回读。
- **契约**：
  - 精选区最多 25 条，优先展示必看与高 Streak 项目。
  - 单卡 JSON 编码体积严格控制在 25,000 字节以下，超出自动切分为 `(1/N)`。
  - 投递后强制调用 `im/v1/messages/{message_id}` 回读校验，记入审计日志。

## 3. 卡片外观设计与验收标准

卡片外观已在沙盒环境完成真实全页渲染，并通过视觉模型真实验收：
- **外观预览图片**：`preview/trendshift-card-preview.png`
- **设计要点对照**：
  1. **暗黑极简科技质感**：沉浸式深灰蓝基调，对比度舒适，避免视觉疲劳。
  2. **双层浏览模式**：
     - 上层**决策精选区**：一眼扫完重点项目、业务关联合理推导与证据链。
     - 下层**折叠原文区**：5 个榜单默认收起，点开即看原始排名。
  3. **字符与排版零瑕疵**：纯矢量 SVG 与跨平台无衬线字体对齐，彻底根绝系统缺字豆腐块。
